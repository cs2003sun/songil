## 2단계·3단계: 미리 만들 문장 목록 (phrases.json)

- 글자 수는 ElevenLabs가 세는 방식대로 공백과 문장부호를 포함한 값이에요. 표현이 여러 개면 모두 더했어요.
- 녹음 파일 이름은 `static/audio/{id}_{번호}.mp3`예요. 번호는 1부터 시작해요. 예: `move_right_1.mp3`, `move_right_2.mp3`
- `static/audio/manifest.json`에 `{"id": 파일 개수}`를 적으면 앱이 그 개수만큼 번갈아 써요. `generate_audio.py`가 자동으로 만들어요.
- 같은 물건의 다른 이름(머그, 핸드폰, 숫가락 등)은 대표 이름 하나로 말해요. 예: "숫가락 찾아줘" → "숟가락을 찾아볼게요".
- 위치 대답("어디")은 짧은 문장을 이어 붙여요. 예: `pos_left` + `dist_near` + `where_hand_right` → "왼쪽에 있어요. 팔이 닿는 거리예요. 손은 오른쪽으로 옮겨 보세요." 조합 54가지를 따로 만들지 않아서 크레딧이 줄어요.
